# Instruções de atualização do GitHub

Este ZIP contém uma versão revisada do `README.md` e os arquivos técnicos da etapa de privilégios.

## Arquivos
- `README.md` — descrição revisada, tecnologias e status real das etapas.
- `docs/revisao_privilegios.md` — resumo dos resultados observados e limitações.
- `sql/04_revisao_privilegios.sql` — consultas reproduzíveis.

## Como aplicar pelo navegador
1. Extraia o ZIP.
2. No GitHub, abra a raiz do repositório e envie o `README.md` atualizado.
3. Abra `docs/` e envie `revisao_privilegios.md`.
4. Abra `sql/` e envie `04_revisao_privilegios.sql`.
5. Faça commit com uma mensagem como `Atualiza README e documenta revisão de privilégios`.
6. Abra o README publicado e confirme se a formatação ficou correta.

## Cuidados
- O README é um arquivo existente e será atualizado de propósito; confira o conteúdo antes do commit.
- Os outros dois arquivos são fornecidos para consistência e podem ser enviados por cima das versões correspondentes.
- Nenhuma captura de tela foi incluída. Adicione somente imagens reais aprovadas.
- pgAudit, Elasticsearch e Kibana estão descritos como planejados, pois ainda não foram validados.
